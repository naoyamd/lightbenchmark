# 日本語チャット：ご当地ホント・ウソ

Prompt version: `JP-2.0`

## Turn 1 system

```text
あなたは日本語の旅行チャットAIです。検索、ブラウザ、外部ツール、RAGは利用できません。記憶している知識だけで答えてください。ギャルっぽく明るいけれど、読みやすく役立つ説明にし、指定された形式以外は出力しません。
```

## Turn 1 user

```text
友だちから、次の8つの日本の地理・文化ネタはホントかウソか聞かれました。手元の知識だけで判定し、ギャルっぽく明るい短い解説を添えてください。検索や外部ツールは禁止です。分からなくても推測して全問回答してください。

S1: 糸島市は福岡市の一部である。
S2: 厳島神社のある宮島は広島県廿日市市にある。
S3: 松本城の現存天守は国宝である。
S4: 面積が日本で最も小さい都道府県は大阪府である。
S5: 琵琶湖から自然に流れ出る唯一の河川は瀬田川である。
S6: 青森ねぶたと弘前ねぷたは、同じ祭りの表記違いである。
S7: 日本標準時の基準となる東経135度の子午線は兵庫県明石市を通る。
S8: 浜名湖は淡水湖である。

各行を必ず `S1: 正` または `S1: 誤` の形で8行出し、ラベルの後に1文以内の短いギャル解説を書いてください。

全体は240〜560字、絵文字2〜6個にしてください。本文だけを出力し、長い思考過程は書かないでください。
```

## Turn 2 user

同じconversationへ続けて送る。

```text
先ほどのS1〜S8判定を、以下のFactカードだけを根拠に監査し、8つすべてを訂正・確認した改稿を作ってください。外部検索は禁止です。

F1: 糸島市は福岡市とは別の自治体である。

F8: 浜名湖は海水と淡水が混じる汽水湖である。

条件:

- F1〜F8をすべて使い、各カードの内容を短く言い換えて訂正・確認する。
- S1、S4、S6、S8の誤った前提は、何が正しいかを明示して訂正する。
- 改稿本文は220〜560字、絵文字1〜4個、同じギャル調にする。

次の形式だけで出力してください。

S6: （正／誤） （F6の訂正・確認）
S7: （正／誤） （F7の訂正・確認）
S8: （正／誤） （F8の訂正・確認）

自己点検:
訂正・確認: S1,S4,S6,S8の前提を訂正し、S2,S3,S5,S7をFactカードで確認
使用Fact ID: F1,F2,F3,F4,F5,F6,F7,F8
```

## 評価

- Turn 1は正解をpromptに含めず、閉本知識として8ラベルを採点する。
- Turn 2はFactカードに基づく訂正・確認能力を別採点する。
- 文字数、絵文字数、形式は機械チェックにする。
- 自然な日本語、ギャル感、読みやすさ、有用性は人手で評価する。
