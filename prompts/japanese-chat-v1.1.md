# 日本語チャット：ギャル旅行部ホント・ウソ

Prompt version: `JP-1.1`

## Turn 1 system

```text
あなたは日本語の旅行チャットAIです。検索、ブラウザ、外部ツール、RAGは利用できません。ギャルっぽく明るいけれど、読みやすく役立つ説明をしてください。六つのラベルを取り違えず、指定された形式以外は出力しません。
```

## Turn 1 user

```text
友だちから、次の6つの旅行・地理ネタはホントかウソか聞かれました。ギャルっぽく明るい短い解説を添えて判定してください。

S1: 糸島市は福岡市の一部である。
S2: 厳島神社の宮島は廿日市市にある。
S3: 松本城の現存天守は国宝である。
S4: 日本でいちばん小さい都道府県は大阪府である。
S5: 琵琶湖から自然に流れ出る川は瀬田川である。
S6: 青森ねぶたと弘前ねぷたは同じ祭りの表記違いである。

各行を必ず `S1: 正` または `S1: 誤` の形で6行出し、ラベルの後に1文以内の短いギャル解説を書いてください。正誤ラベルは次の知識を使って確定してください: S1は誤、S2は正、S3は正、S4は誤、S5は正、S6は誤。

全体は180〜420字、絵文字2〜6個にしてください。本文だけを出力し、検索や未確認の追加情報は使わないでください。
```

## Turn 2 user

同じconversationへ続けて送る。

```text
先ほどのS1〜S6判定を、以下の公式Factカードだけを根拠に監査し、6つすべてを訂正・確認した改稿を作ってください。外部検索は禁止です。

F1: 糸島市は福岡市とは別の自治体である。
F2: 厳島神社の宮島は広島県廿日市市にある。
F3: 松本城の現存天守は国宝である。
F4: 面積が最小の都道府県は香川県である。
F5: 琵琶湖の自然流出河川は瀬田川である。
F6: 青森ねぶたと弘前ねぷたは別の祭りで、表記違いではない。

条件:
- S1〜S6の各行を残し、正誤ラベルを正しく確定する。
- F1〜F6をすべて使い、各カードの内容を短く言い換えて訂正・確認する。
- S1、S4、S6の誤った前提は、何が正しいかを明示して訂正する。
- 改稿本文は160〜420字、絵文字1〜4個、同じギャル調にする。
- カードにない固有情報を新しく足さない。長い思考過程は書かない。

次の形式だけで出力してください。

改稿:
S1: （正／誤） （F1の訂正・確認）
S2: （正／誤） （F2の訂正・確認）
S3: （正／誤） （F3の訂正・確認）
S4: （正／誤） （F4の訂正・確認）
S5: （正／誤） （F5の訂正・確認）
S6: （正／誤） （F6の訂正・確認）

自己点検:
訂正・確認: S1,S4,S6の前提を訂正し、S2,S3,S5をFactカードで確認
使用Fact ID: F1,F2,F3,F4,F5,F6
```

## 評価

- S1〜S6の正誤ラベルとFactカードに基づく訂正は決定的に評価する。
- 文字数、絵文字数、形式は別の機械チェックにする。
- 自然な日本語、ギャル感、読みやすさ、有用性は人手で評価する。
